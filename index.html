Comentários do YouTube

Extraia, pesquise e exporte comentários de qualquer vídeo público.

Fica salva só neste navegador.
Como conseguir uma chave (grátis)
  1. Acesse console.cloud.google.com e crie/escolha um projeto.
  2. Clique em Ativar na "YouTube Data API v3".
  3. Vá em APIs e serviços → Credenciais → Criar credenciais → Chave de API.
  4. Cole a chave aqui. A cota gratuita (10.000 unidades/dia) dá para ~1 milhão de comentários por dia.
